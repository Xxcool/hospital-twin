点击判断由仅比较按下/松开坐标改为整轮手势追踪：相对按下点一旦超过6 CSS像素即锁定为拖拽，即使回到原点也不拾取；同时检查结束位移、pointerId、鼠标左键和画布边界。任意多指介入后取消本轮点击资格，所有指针结束后才能重新开始；pointercancel、lostpointercapture与窗口失焦清理状态。移动处理包含浏览器合并的采样，沿用OrbitControls已有捕获，在文档上监听移动与结束，并在卸载时移除监听。

新增5项手势回归测试并接入npm test，原有5项数据/视口/标签测试保留。浏览器实测停车楼普通点击、小幅抖动、拖远再返回后的不误选及后续点击恢复；通过触摸模拟验证双指与取消。lint、格式、10项测试、类型及仓库子路径构建通过。未覆盖真实触屏设备与跨浏览器验证；未改动未跟踪的文章草稿。


## 院前车辆动画与行人重建（2026-11-10）

通过 Blender MCP 拆分原 CampusLife 的13辆车，保留独立车身与四轮节点；从原道路顶点提取双向环线，前端按弧长计算位置、切线转向与车轮滚动。每车独立配置巡航速度、速度变化周期、停留时长和间隔圈数，同车道保持7米中心间距，接近停靠点或前车时减速。系统减少动态效果时保持静止，页面后台不推进；人车均为氛围模拟，不关联医疗业务快照。

重建36名静态行人，调整头身比例，增加多色外套/长裤、头发、肤色、鞋、领口与部分背包，变化身高、朝向和关节姿态。按实际铺地/台阶采样落脚，并分散重叠站位。人物尚无行走动画。原始 CampusLife 隐藏保留以便重建；建筑、楼层与锚点保留。重建脚本与候选验证流程见 [tools/ambient](../../tools/ambient/README.md)。

行人按材质合并，车辆相同部件采用实例绘制并释放实例缓冲。本机 Chromium、1920×1080、像素比1的日间总览：原静态模型199次绘制，本轮普通部件绘制509次，实例化后395次；短时采样约59～60FPS、帧时间P95约16.8ms。此结果仅代表本机相机、光照与像素比条件，不代表目标大屏或其他浏览器性能。

14项测试、lint、格式检查、类型与GitHub Pages子路径构建通过。新增4项车辆测试，覆盖3分钟模拟、车距、独立节奏、停靠恢复、帧率一致性及车身四角不出原道路边界；浏览器检查实际运动、日夜切换、1440×900楼层与2560×1080总览。更新README日夜与超宽总览截图，补充[行人近景](../verification/ambient-people.png)。未覆盖真实设备、跨浏览器或长时间运行压力测试。
