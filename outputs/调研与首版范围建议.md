# 同济医院光谷院区智慧运行中心：调研与首版范围建议

调研日期：2026-10-21。已确认范围并进入代表区域制作。当前有效设计和实现进度见[方案说明](design-proposals/方案说明.md)，本文件仅保留调研事实及范围依据。

## 项目定位

以公开资料可辨识的院区建筑和空间关系为原型，制作可交互的院区运行演示。建议首版围绕“哪里服务压力较集中、该区域有哪些开放资源、模拟时段切换后有什么变化”展开。

固定展示声明：“演示项目｜运行数据均为模拟，不代表医院真实运行情况”。内部空间另标“示意设计，非真实平面”；空间与资源位置未经核实的部分明确标示。

## 调研结论与资料边界

1. **对象与地址明确。** 医院官网列明光谷院区位于武汉市东湖新技术开发区高新大道501号，亦称中德友好医院。不能混用汉口、中法新城、同济军山或其他光谷医院的建筑与科室分布。
2. **一期综合医疗体具有明确空间主线。** 医院2015年报道记载：180米南北向阳光走廊连接门急诊、医技和南北两座10层住院楼。这些是历史建筑描述，不是2026年竣工测绘结果。
3. **2021年公开环评提供可核对的总图。** 《光谷院区配套项目（质子大楼）——使用质子治疗系统项目环境影响报告书》落款2021年11月。正文第20页、PDF第34页图1-3可辨：门急诊位于南侧入口一带，医技在其北侧，住院建筑位于东侧，儿童医疗中心位于西侧，停车楼位于更西侧，质子项目位于东北侧。图中包含当时拟建工程，不能将所有线条当作当前建成状态。
4. **儿童医院应保留在总览中。** 医院2023年7月“启用一周年”报道证实其已投入使用。不能继续把其所在区域处理成早期一期照片里的空地或地面停车场。首版建议保留建筑和名称，不展开儿童门急诊业务。
5. **急诊资料需采用改造后的边界。** 医院2023年10月报道：新急救中心于10月10日启用，面积由1900平方米增至2800平方米，新增诊疗及留观空间。此报道能确认改造发生，不能提供当前完整室内平面或当前可用床位总数；“新增12张留观床位”不能当作总容量。
6. **外观以可辨识特征为重点。** 建筑实景可观察到入口弧形雨棚、浅色金属或板材立面观感、玻璃幕墙、横向窗带、低层入口与较高住院建筑的高差，以及入口绿地。大学官网报道也提及弧形玻璃幕墙施工。演示应保留这些特征，不把院区改造成一组相同的发光玻璃盒子。供应商案例页照片仅作为外观观察资料，其文章标题不能单独证明照片中每栋建筑的身份和拍摄时间。
7. **不锁定当前医院规模。** 早期资料的面积、规划床位和门诊设计容量存在年代与口径差异；本轮未取得2026年完整竣工总图、当前内部空间清单及真实运行接口。历史规模不进入实时KPI，也不作为仿真容量的默认值。2026年停车楼改建和新连廊中标公告仅证明工程采购，不能据此认定工程已经竣工。

## 首版范围建议

### 空间

- 院区总览：以可核实的主要建筑群、入口、主路和绿化关系建立识别度；建筑外壳按重要程度分级制作，未核实细节简化并说明。
- 重点：综合门诊示意区、急诊示意区，分别可选择和查看详情。门诊聚焦候诊与接诊服务点；急诊聚焦接诊与留观资源的模拟使用状态。
- 背景：医技、住院楼、儿童医院、停车楼与质子建筑以外壳和名称帮助理解院区；不在首版增加其独立运营专题。
- 内部表达：只做与演示有关的少量功能分区，不制作全楼逐层漫游。示意内部不直接绑定到未经核实的真实楼层号或诊室号。

### 业务与数据

所有数值均待范围确认后统一生成，以下为建议口径，非医院事实。

| 层级   | 建议内容                               | 口径约束                                |
| ---- | ---------------------------------- | ----------------------------------- |
| 总览   | 演示范围累计接诊人次、当前候诊人数、门急诊分时到诊趋势        | 明确仅含首版模拟服务区；不标成全院真实总量；累计量与当前量分开     |
| 门诊详情 | 当前候诊人数、近30分钟已开始接诊者等候时长中位数、开放接诊服务点数 | 不将人数、就诊人次和陪同人员混为一项；资源总量为演示配置        |
| 急诊详情 | 当前待接诊人数、留观占用数/模拟可用总数、开放接诊服务点数      | 不涉及分诊标准、病情评级或临床处置建议；留观人员与待接诊人员按状态分开 |
| 资源分布 | 上述服务点与留观区域的示意分布                    | 不添加未经核实的人员定位、设备实时位置或真实床号            |

不默认增加能耗、安防视频、资产台账、设备故障、工单、财务、科研、临床质控等专题。

模拟采用固定种子与统一时钟；到诊、等待、接诊、留观和离开等状态相互衔接，同一时刻的KPI、趋势、区域颜色和详情从同一快照汇总。压力颜色仅表示演示配置下的相对负荷，阈值为演示设定，不代表医院运营考核标准。第一版不建立独立综合评分或告警闭环。

### 最小交互闭环

1. 默认展示院区，门诊和急诊保留清晰名称与压力标记。
2. 点选区域，场景高亮并适度聚焦，侧面切换该区域的详情；总览上下文仍可返回。
3. 切换模拟时段，保留所选对象，场景状态、资源分布和图表同步更新。
4. 一键回到院区总览。支持有限旋转与缩放，不做自由飞行或患者级轨迹。

建议四个演示时点：08:00开诊、10:00门诊集中、15:00午后回落、20:00急诊关注。名称与曲线均为人为编排的演示情境，不是对医院真实规律的推断。若采用近30分钟统计或全日趋势，需由同一连续模拟过程生成，不能只拼接四组无关联随机数。

## 下一轮三种整屏视觉方向

同一空间范围、同一业务内容、同一模拟时点和关键数值用于三张候选图，比较视觉本身，不靠增加模块制造差异。以下均为原创方向建议，尚未生成图像。

| 方向          | 构图与材质                                                     | 适用与代价                              |
| ----------- | --------------------------------------------------------- | ---------------------------------- |
| A 日光庭院，优先推荐 | 暖白与浅灰底、深墨绿文字、低饱和青绿状态色；院区占主要视域，浅色建筑、克制玻璃、柔和日照和庭院绿地；细线面板与留白 | 最能保留医院与园区的气质；需要验证浅色建筑与背景的层次以及投屏对比度 |
| B 石墨运行台     | 深石墨绿灰底，银灰建筑与淡暖光，青绿及琥珀用于局部状态；侧面信息更紧凑，保留入口和医街主线             | 适合偏暗展示空间；需防止阴影吞没建筑结构，控制透明和发光效果     |
| C 建筑图志      | 米白或浅砂色底，模型展台式轴测构图，哑光陶瓷建筑，少量铜色或陶土色索引，图表和标签更强调网格秩序          | 空间层次清楚、网页实现相对稳健；写实氛围较弱，仍须保留可辨识建筑轮廓 |

共同原则：三维主场景约占可用视域55%—65%，其余组织总览与所选区域详情；不采用环形仪表堆叠、全屏光束、无意义飞线、满屏透明卡片。压力状态以文字与色彩共同表达，红色仅少量使用，不给医院建筑长期铺满红色。

暂以16:9、1920×1080逻辑画布、桌面浏览器鼠标操作作为设计假设；若实际为超宽屏、触摸屏或其他观看条件，应在候选图生成前调整。

## 选方案后的制作验证路线

选定完整大屏方案后，代表区域建议采用“门诊入口弧形雨棚＋玻璃前厅外壳＋阳光走廊片段＋一处明确标注的候诊示意区”。外观结构与示意内部边界分开，急诊压力区域可用明确标记联动。

通过实际连接的Blender MCP制作，保存.blend及必要依赖，再导出网页资产。新项目按React + TypeScript + Vite + Three.js实现。网页验证建筑比例、玻璃、阴影、文字可读性、拾取与时段联动；性能在实际设备上记录首载、帧率和资源消耗。优先采用可烘焙光照、实例化植被和受控透明层。具体预算待确认展示设备后确定，不预先宣称任何帧率或加载时长已经达标。

展示实际网页效果及相对于选定设计的差异，用户确认后定稿，再逐区扩展；不把AI候选图当作已经实现的效果。
