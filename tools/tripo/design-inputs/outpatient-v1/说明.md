# 综合门诊精细单体参考 v1

本组基于用户实景照片与已确认日间效果图生成，不使用简化模型截图作为外观品质依据。目标是门诊入口低层弧形单体，不包含后侧医技、临床楼群。

- 01-front.png：正面偏斜主图，优先作为确认后的Tripo单图试制输入。
- 02-side.png：右侧斜视，说明侧墙和屋顶关系。
- 03-back-schematic.png：背面推演，未核实，不代表医院真实后立面。

目前三图均待用户确认。窗格、屋顶设备位置存在细节漂移，不能声称为精确一致的多视图或直接拼图提交。真实弧形与比例以实景核对，图像不提供实测尺寸。内部仍须独立示意设计，Tripo外壳不自动具备楼层展开能力。

下一步：确认主图 → 接入Tripo并核实额度/输入方式 → 单体试制 → Blender校准及结构拆件 → 网页视觉与交互检查。本轮未生成3D、未替换运行资产、未测试性能。
